# The Mindful Mama 🌷
A soft, floral static website for honest motherhood reflections and gentle encouragement.

## Preview
Open `index.html` in a web browser. All pages work without a build step.

## Publish with GitHub Pages
1. Create a **public** repository named `the-mindful-mama` under the GitHub account `themindfulmama`.
2. Upload these files and the `posts` directory at the repository root.
3. Open **Settings → Pages**, select **Deploy from a branch**, then select `main` and `/ (root)` and save.
4. GitHub Pages will publish to `https://themindfulmama.github.io/the-mindful-mama/` when deployment completes.

## Edit
- Update site text in the corresponding HTML files.
- Global colors and typography are in `style.css`.
- Add future articles to `posts/` and link them from `journal.html`.

No checkout, forms, tracking, or third-party analytics are implemented. Google Fonts are loaded from Google; change the stylesheet if you prefer self-hosted/system fonts.

# The Mindful Mama 🌷

A soft floral website for honest motherhood reflections and gentle encouragement.

## Preview
Open `index.html` in your browser.

## Publish with GitHub Pages
Go to Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save. Your site will be at https://themindfulmama.github.io/ once Pages deploys.

## Editing
Update content in the HTML files, global styles in `style.css`, and journal articles in `posts/`. No store payments, email collection, or analytics are set up yet.
